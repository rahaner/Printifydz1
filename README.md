# Printify DZ

Site portfolio de Printify DZ (impression DTF et cartes de visite).

- `index.html` : la page unique
- `images/` : logo, carte de visite et photos des realisations

## Mettre en ligne avec GitHub Pages
1. Creez un depot sur GitHub (ex. `printify-dz`).
2. Envoyez tout le contenu de ce dossier (`index.html`, `images/`, `.nojekyll`) a la racine du depot.
3. Settings > Pages > Source : branche `main`, dossier `/ (root)` > Save.
4. Le site sera disponible a `https://VOTRE-NOM.github.io/printify-dz/`.

Pour utiliser dzprintify.com : Settings > Pages > Custom domain.
